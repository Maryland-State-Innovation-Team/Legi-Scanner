State Highways - Highway Work Permits - Notice 
 
 
This bill requires a person that submits an application to the State Highway Administration 
(SHA) for a permit to conduct work on a State highway for a Type 2 or Type 3 project to 
provide notice of the application – within 10 days after the application is submitted – to 
each member of the General Assembly who represents the State legislative district in which 
the proposed work is to be performed. The notice must include (1) the name of the 
applicant; (2) the location of the proposed work; (3) the expected starting date for the 
proposed work; and (4) a brief description of the nature of the proposed work. The bill 
takes effect July 1, 2026. 
 
 
Fiscal Summary 
 
State Effect:  SHA can implement the bill’s changes using existing budgeted resources. 
Revenues are not affected. 
  
Local Effect:  Local governments that apply for a permit from SHA can provide the 
required notice using existing budgeted resources. Revenues are not affected. 
 
Small Business Effect:  Minimal. 
 
 
Analysis 
 
Current Law:  SHA must construct, reconstruct, and repair State highways as necessary 
and maintain them in good condition. Unless a person has a permit from SHA, a person 
may not: 
 
 
make an opening in any State highway;



 
change or renew any structure placed on any State highway; 
 
dig up any State highway for any purpose, including the placement of pipes, sewer, 
poles, wires, or rails; 
 
plant or remove any tree on any State highway; or 
 
place any obstruction or improvement on any State highway. 
 
If any such work is permitted by SHA, the work must be performed to the satisfaction of 
SHA and under its supervision. The person to whom the permit is issued or by whom the 
work is done must pay the cost of replacing the highway in as good a condition as before 
the work was done. 
 
When considering the approval of a permit, SHA categorizes a proposed project into one 
of three project categories based on the anticipated impact to the State highway. A Type 1 
project involves minimal construction within the State’s right-of-way and may include 
elements such as entrance improvements and/or minor intersection mitigation. A Type 2 
project is similar in scope to a Type 1 project but may include more complex or involved 
elements, such as additional through-lanes, roadway lighting, and/or traffic signal 
installation. A Type 3 project involves significant roadway reconstruction and/or new 
roadway alignment that directly impacts the interstate system and may include elements 
such as access breaks, median breaks, and/or noise walls.
